Online backup — কীভাবে চালু করবেন

অ্যাপ সবসময় অফলাইনে কাজ করে; ডাটা আগে ফোনে সেভ হয়। অনলাইন হলে কপি GitHub-এর একটি secret Gist-এ জমা হয়।
১) GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token।
২) শুধু gist permission টিক দিন, মেয়াদ বেছে Generate করুন, token কপি করুন।
৩) এখানে Token ঘরে Paste করে Connect চাপুন।
এরপর ডাটা বদলালে নেট থাকলে ৫ সেকেন্ডের মধ্যে অটো ব্যাকআপ হয়; নেট না থাকলে "Changes pending" থাকে এবং নেট এলে নিজে পাঠায়। Restore চাপলে অনলাইন কপির রেকর্ড এই ফোনের রেকর্ডের সাথে মিশে যায় (merge), আর Settings/Formula রিপ্লেস হয়।
সতর্কতা: Token শুধু এই ফোনে থাকে। কাউকে দেবেন না; হারালে GitHub থেকে revoke করুন। Secret Gist তালিকায় দেখা যায় না, কিন্তু লিংক জানলে কেউ পড়তে পারে।

Operating Hours

HH:MM লিখুন (24-hour)। শুধু সংখ্যা লিখলে : নিজে বসবে। 12:88 বা 24:10 এর মতো ভুল সময় লাল error দেখাবে। "Now" চাপলে বর্তমান সময় বসে।

Auxiliary Power

Generation ও প্রতিটি Bus-এর consumption দিন; W, kW বা MW ব্যবহার করা যাবে। Add Bus দিয়ে Bus বাড়ান।

Generation

প্রতিটি Meter: (Current − Previous) × MF। Total = সব Meter-এর difference-এর যোগফল × MF। Common MF ON থাকলে একটি MF সব জায়গায় চলে; OFF করলে প্রতিটির আলাদা MF ঘর আসে। Daily Summary-তে Export ও Import প্রতিটিতে Active বা Reactive বেছে নেওয়া যায় এবং যত খুশি Meter যোগ করা যায়। Next Hour ▶ Current reading Previous-এ সরায়। Remember readings ON থাকলে অ্যাপ বন্ধ করলেও reading থাকে।

Clear Data বাটন

প্রতিটি Tab-এর 🗑 Clear Data সেই Tab-এর ইনপুট ও ফলাফল মুছে দেয় (Generation-তে Common MF-এর মান থাকে)। Saved Records-এ এটি সব সেভ করা রেকর্ড মোছে। Formulas Tab-এ Restore All Defaults সব ফর্মুলা ও parameter ডিফল্টে ফেরায়।
